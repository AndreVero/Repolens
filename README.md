# RepoLens Mobile

RepoLens Mobile is an Android application that visualizes repository intelligence reports generated by IBM Bob. It provides a mobile-friendly interface to explore code architecture, features, risks, testing coverage, and PR readiness insights.

## Overview

This app is designed to work with JSON reports generated by IBM Bob after analyzing a codebase. It does **not** call any AI API directly - it simply loads, parses, and visualizes pre-generated analysis reports.

## Features

### 📊 Repository Overview
- View repository summary and key metrics
- See module count, feature count, and risk indicators
- Check PR readiness and architecture confidence scores
- Navigate to detailed sections

### 🏗️ Architecture Visualization
- Explore architecture layers (UI, Domain, Data)
- View data flow between components
- See architectural strengths and concerns
- Review recommendations

### 📦 Modules & Features
- Browse project modules with risk levels
- View module dependencies and responsibilities
- Explore detected features with complexity ratings
- See feature components (ViewModels, UseCases, Repositories)
- Check test coverage per module/feature

### ⚠️ Risk Analysis
- View risks grouped by severity (Critical, High, Medium, Low)
- See affected files and modules
- Get recommendations and suggested tests
- Understand why each risk matters

### 🧪 Testing Insights
- See existing test coverage
- Identify missing test areas
- Get suggested test cases
- View testability concerns

### 🔗 Technical Deep Dives
- **Dependency Injection**: Hilt modules, scopes, and DI patterns
- **Concurrency**: Coroutines, Flows, Dispatchers usage
- **UI Layer**: Compose screens, state management, navigation
- **PR Readiness**: Score, checklist, QA items, rollback plan

## Tech Stack

- **Language**: Kotlin
- **UI Framework**: Jetpack Compose with Material 3
- **Architecture**: MVVM with Clean Architecture principles
- **Dependency Injection**: Hilt
- **Navigation**: Navigation Compose
- **State Management**: StateFlow
- **JSON Parsing**: Kotlinx Serialization
- **Build System**: Gradle with Version Catalogs

## How It Works

1. **Report Generation**: Use IBM Bob IDE to analyze your repository and export a JSON report
2. **Report Loading**: Place the JSON file in `app/src/main/assets/`
3. **Parsing**: The app uses Kotlinx Serialization to parse the JSON into Kotlin data classes
4. **Visualization**: Navigate through screens to explore different aspects of the analysis
5. **Insights**: Review risks, test gaps, and PR readiness recommendations

## IBM Bob Integration

This app is designed to work with IBM Bob's repository analysis feature:

1. Open your project in an IDE with IBM Bob
2. Ask Bob to analyze your repository architecture
3. Request a comprehensive JSON export of the analysis
4. Save the JSON as `repolens_sample_report.json`
5. Place it in the app's assets folder
6. Build and run the app to visualize the insights

### Expected JSON Schema

The app expects a JSON report with the following top-level structure:

```json
{
  "metadata": { ... },
  "repository": { ... },
  "metrics": { ... },
  "architecture": { ... },
  "modules": [ ... ],
  "features": [ ... ],
  "dependencyInjection": { ... },
  "concurrency": { ... },
  "uiLayer": { ... },
  "testing": { ... },
  "risks": [ ... ],
  "prReadiness": { ... }
}
```

See `app/src/main/assets/repolens_sample_report.json` for a complete example.

## Building the App

### Prerequisites
- Android Studio Hedgehog or later
- JDK 11 or later
- Android SDK 28 or higher

### Build Steps

1. Clone the repository:
```bash
git clone <repository-url>
cd Repolens
```

2. Open the project in Android Studio

3. Sync Gradle dependencies

4. Run the app on an emulator or physical device

### Gradle Build

```bash
./gradlew assembleDebug
```

## Key Components

### Data Models
- `RepoLensReport`: Root data class for the entire report
- `Architecture`, `Module`, `Feature`, `Risk`: Domain models
- All models use Kotlinx Serialization annotations

### Repository
- `RepoLensRepository`: Loads JSON from assets with error handling
- Returns `RepoLensResult.Success` or `RepoLensResult.Error`

### ViewModel
- `RepoLensViewModel`: Single shared ViewModel for the entire app
- Exposes `StateFlow<UiState>` (Loading, Success, Error)
- Injected via Hilt

### UI Components
- `MetricCard`: Displays numeric metrics with icons
- `SectionCard`: Clickable navigation cards
- `SeverityBadge`, `ComplexityBadge`, `ConfidenceBadge`: Status indicators
- `FilePathChip`: File path display
- `LoadingState`, `ErrorState`, `EmptyState`: State screens

### Screens
- `OverviewScreen`: Main dashboard
- `ArchitectureScreen`: Architecture layers and data flow
- `ModulesScreen` / `ModuleDetailScreen`: Module exploration
- `FeaturesScreen` / `FeatureDetailScreen`: Feature deep dives
- `RisksScreen`: Risk analysis
- `TestingScreen`: Test coverage insights
- `PrReadinessScreen`: PR checklist and score
- `DependencyInjectionScreen`, `ConcurrencyScreen`, `UiLayerScreen`: Technical details

## Customization

### Adding New Sections

1. Add new fields to data models in `data/models/`
2. Update JSON schema in assets
3. Create new screen composable in `ui/screens/`
4. Add route to `NavRoutes.kt`
5. Add navigation in `NavGraph.kt`
6. Add navigation card in `OverviewScreen.kt`

### Styling

Modify Material 3 theme in `ui/theme/`:
- `Color.kt`: Color palette
- `Type.kt`: Typography
- `Theme.kt`: Theme configuration

## Limitations

- **No Live Analysis**: The app does not perform code analysis itself
- **Static Reports**: Reports must be pre-generated by IBM Bob
- **Single Report**: Currently loads one bundled report (can be extended)
- **No Export**: Insights cannot be exported from the app (view-only)
